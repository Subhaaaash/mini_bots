# STL files

3D-printable parts for the chassis (chassis plate, camera mount, motor
mounts, caster mount, etc.) go here. Empty for now -- add `.stl` files as
they're finalized, one file per part, named for what it is (e.g.
`chassis_plate.stl`, `camera_mount.stl`).

If a part has print settings worth calling out (layer height, infill,
supports, material), note them in this file next to the part name rather
than relying on defaults.
